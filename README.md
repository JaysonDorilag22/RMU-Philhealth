# PRMU-PhilHealth

This repository contains a **React + Vite + Tailwind CSS** project that serves as a **UI-only prototype** for a PhilHealth-style portal.  
All sections (Membership, Benefits, Online Services, Downloads, Updates, and Contacts) are made with **dummy/sample data** and for **demonstration purposes only**.  

⚠️ Disclaimer: This project has no backend, no real PhilHealth data, and is not affiliated with PhilHealth. It is created purely for **UI/UX exploration and design**.
